Como enviar Markdown para o MDView

POST via formulario

<form action="https://seu-usuario.github.io/MDView/render" method="post" target="_blank">
  <textarea name="markdown"># Relatorio</textarea>
  <button type="submit">Visualizar</button>
</form>

POST via fetch

await fetch("https://seu-usuario.github.io/MDView/render", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ markdown: "# Relatorio" })
});

postMessage

iframe.contentWindow.postMessage({
  type: "mdview:render",
  markdown: "# Relatorio"
}, "https://seu-usuario.github.io");

Em GitHub Pages, o POST e interceptado por Service Worker no navegador. Abra a pagina uma vez antes de testar /render.
