Como enviar Markdown para o MDView

POST via formulário

<form action="https://anderitmo.github.io/visualizador-md-com-post/render" method="post" target="_blank">
  <textarea name="markdown"># Relatorio</textarea>
  <button type="submit">Visualizar</button>
</form>

POST via fetch (com download)

await fetch("https://anderitmo.github.io/visualizador-md-com-post/render", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ markdown: "# Relatorio", download: true })
});

GET com download automático

https://anderitmo.github.io/visualizador-md-com-post/?md=%23%20Titulo&download=true

Em GitHub Pages, o POST e interceptado por Service Worker no navegador. Abra a pagina uma vez antes de testar /render. Use o parâmetro download=true para baixar o arquivo .md automaticamente.
